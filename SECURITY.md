# Security Policy

`https://antigravityreset.online/mcp` is a stateless, read-only public MCP endpoint.

- It does not require authentication, cookies, or Google account credentials.
- It performs no write operations (`readOnlyHint: true`, `destructiveHint: false`).
- All reset entries are sourced from public X announcements by `@_mohansolo` and the Antigravity team and linked to their primary post URLs.

If you discover a security or data integrity issue, please open an issue on this repository.
